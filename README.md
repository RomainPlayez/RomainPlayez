## Projet en avant : FinSight Agent

Agent d'analyse financière combinant données structurées (SEC EDGAR / XBRL / SQL) et recherche sémantique (RAG) sur les 10-K de 8 grandes entreprises cotées, orchestrés par un LLM via function calling (API OpenAI, sans framework).

![Démo FinSight Agent](https://raw.githubusercontent.com/RomainPlayez/finsight-agent/main/docs/combined.gif)

- Pipeline de données automatisé depuis l'API SEC EDGAR vers SQLite
- Recherche sémantique (RAG) avec embeddings OpenAI et ChromaDB
- Agent conversationnel orchestrant les deux sources par function calling
- Plusieurs anomalies réelles de données financières XBRL diagnostiquées et corrigées

**Stack** : Python, API OpenAI, SQLite, ChromaDB, API SEC EDGAR, BeautifulSoup
